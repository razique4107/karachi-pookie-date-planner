# Contributing to Little Karachi Date Invitation

Thank you for your interest in contributing! Whether you are fixing a typo, suggesting a new iconic Karachi date spot, or polishing an interaction, contributions are welcome.

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/little-karachi-date-invitation.git
   cd little-karachi-date-invitation
   ```
3. **Create a topic branch**:
   ```bash
   git checkout -b feature/my-cool-feature
   ```
4. **Make your changes**:
   - Keep all copy and date options configurable inside `src/config/siteConfig.ts`.
   - Maintain the warm ivory and burgundy editorial design system in `src/index.css`.
   - Ensure the app remains 100% client-side with no secret keys or backend requirements.
5. **Run linting and test suite**:
   ```bash
   npm run lint
   npx tsx tests/audit.ts
   npm run build
   ```
6. **Commit and push** your changes:
   ```bash
   git commit -m "feat: add new Karachi chai spot"
   git push origin feature/my-cool-feature
   ```
7. **Open a Pull Request** against the `main` branch.

## Code of Conduct

Please keep discussions, reviews, and humor kind, warm, welcoming, and respectful. Peak pookie energy only! 💗
